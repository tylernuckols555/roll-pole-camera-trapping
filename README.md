# The Roll-Pole: Camera Trapping in Elephant Country

An interactive, scroll-based lesson on camera-trap field methods, built for School for Field Studies students. It teaches the method through the roll-pole: a low-cost, freestanding camera-trap mount for monitoring elephants in active crop fields adjacent to Kuiburi National Park, Thailand. All figures, charts, and data come from the study.

## What it is

A single self-contained `index.html` (about 3 MB) with every figure embedded. Charts, the annotated schematic, and the knowledge checks run in plain JavaScript with no build step. The three field videos open on YouTube in a new tab. An internet connection loads the web fonts and the video links; the rest runs offline.

## Contents

- Fundamentals of camera trapping (PIR sensors, study design, detection rates)
- The deployment problem in open agricultural fields and the roll-pole design
- Construction cost, the two-camera configuration, and equipment results
- Interactive detection data by hour, month, and crop type
- Community participation, ethics, limitations, and how to adapt the method

## Source
